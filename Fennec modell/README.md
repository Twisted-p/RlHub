# RL Hub

`RL Hub` er en lett, Rocket League-inspirert webapp-prototype som samler flere nyttige områder i én clean og animert flate.

## Innhold

- Dashboard for rask oversikt
- Garage-seksjon for presets og design
- Training-modul for daglige rutiner
- Market watchlist med roterende status

## Kjøring

Åpne `index.html` direkte i nettleseren.

## Neste steg

- Koble moduler til ekte data
- Gjøre garage og market interaktive med egne views
- Flytte prosjektet til React/Vite når Node-oppsett er tilgjengelig
